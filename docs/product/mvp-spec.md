# Netify MVP Product Specification & Vertical Slices

## Core Value Proposition
Netify is a mobile-first AI Collections + Business Memory tool for African SME owners. It answers four core questions:
1. Who owes me money?
2. What did they promise?
3. Who needs attention right now?
4. How do I get paid?

## Development Vertical Slices
- **Slice 1: Foundation + Auth + Tenancy + Customer**
- **Slice 2: Invoices + Payments + Deterministic Balances**
- **Slice 3: Commitments + Payment Promise Tracking**
- **Slice 4: Business Memory + Evidence Linking**
- **Slice 5: Deterministic Risk Engine + Collections Priority Queue**
- **Slice 6: AI Investigation Chat (Hybrid RAG)**
- **Slice 7: Contextual AI Collection Messaging (WhatsApp/SMS ready)**
- **Slice 8: Notifications & Alerts**
- **Slice 9: RevenueCat Subscriptions & Entitlements**
